# Svenska Brunnslock, klikattava prototyyppi (P4a)

Kevyiden kaivonkansien ostopolku: etusivu, kategoria, tuote, ostoskori, kassa ja kiitos. Oletuskieli suomi, ruotsi kielivalinnasta.

- Sivut ovat Claude Design -canvaksen artboardeja (`*.dc.html`) sellaisenaan.
- `support.js` ajaa ne selaimessa: `{{ }}`-reiät, `sc-for`, `sc-if`, `dc-import` ja komponenttien tila.
- Päivitys canvakselta: `tools/sync-from-canvas.sh <canvaksen project-kansio>`, sitten commit ja push.

Hinnat, mitat ja rahdit ovat esimerkkejä.
